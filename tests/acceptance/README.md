# Answer Image Infrastructure Acceptance

These tests explicitly start local processes and use temporary databases,
workspaces, TLS certificates and uniquely named buckets. They never connect to
an existing MinIO endpoint or read application credentials. Default `make test`
skips this directory. An enabled run fails if a required binary is missing.

Prerequisites: `minio`, `nginx` with PCRE and TLS support, `openssl`, and Git with
the legacy commit `3a40c3e1f5c9eade9bd966444010d25a2e9b6e88` available locally.
No Docker daemon is required. Run from the repository root:

```bash
NIANLUN_RUN_IMAGE_INFRA_ACCEPTANCE=1 \
NIANLUN_ACCEPTANCE_MINIO_BIN=/absolute/path/to/minio \
NIANLUN_ACCEPTANCE_NGINX_BIN=/absolute/path/to/nginx \
uv run pytest tests/acceptance -q
```

Binary overrides are optional when executables are on `PATH`.
`NIANLUN_ACCEPTANCE_OPENSSL_BIN` can override `openssl` in the same way.

The 29 cases cover:

- Real MinIO path-style HTTP/TLS, private CA verification and bad credentials.
- Versioning enabled/disabled, exact bytes, adapter reopen and version deletion.
- URL/Data URL completion, replay, source revocation and original-byte recovery
  in a new Python process using the persisted database and object locator.
- Expired upload ownership, a replacement object and late PUTs before/after GC.
- The shipped nginx map with only listener/upstream addresses changed: actual
  `nginx -t`, precise routes/methods, denied management paths, real API CORS,
  malformed requests, upstream failure, query/Bearer log suppression and
  unbuffered 2 MiB SSE events.
- A database and v2 snapshot generated by the actual old code, explicit offline
  checkpoint/backup, repeatable migration, dry-run, v3 backfill, legacy-reader
  rejection, idempotent rerun and complete backup restoration into a new folder.

OpenAI SDK compatibility uses deterministic ASGI routes and is part of the
ordinary test suite; it does not contact OpenAI:

```bash
uv run pytest tests/api_server/test_answer_image_sdk.py -q
```

Validated locally with MinIO source tag `RELEASE.2025-04-22T22-12-26Z` built using
Go 1.24.2 (the binary reports `DEVELOPMENT.GOGET`), nginx 1.28.0 built with
PCRE2 10.45 / OpenSSL 3.5.0, and OpenAI Python SDK 2.53.0.
Processes are stopped and temporary buckets cleaned at test teardown. Binaries
and source downloads are external prerequisites, not project dependencies.
This suite does not deploy the application or call a real model.
